本笔记由 AI 辅助整理。概念对照文末固定版本的 MCP 官方规范；教学信封、
代码、错误案例与说明模板由本项目独立编写，不是某家模型 API 或 MCP
消息的完整实现。实验没有请求大语言模型，没有模型内部思考记录。

## 一次调用里，至少有三个角色 {#actors}

模型可以提出结构化的工具名与参数；应用决定是否接受和执行；工具程序返回
结果。应用再把结果放进后续模型上下文，模型才可能继续请求工具或作答。
模型发出调用提议，并不等于任务已经执行，也不等于应用已经授予权限。

本实验用固定脚本替代模型提议，用固定文本模板替代最终生成，但中间的
文字检索、球面距离和半径筛选是真正执行的 JavaScript 程序。逐步点击
是为了观察边界，不代表真实产品每个内部步骤都必须要求用户确认。

## 改一份契约，再看程序是否执行 {#contract}

默认问题比较两座图书馆。简化提议为：

```json
{
  "name": "measure_distance",
  "arguments": {
    "from": "main-library",
    "to": "medical-library"
  }
}
```

应用先核对：是不是 JSON 对象？是不是开放工具？字段是否恰好符合契约？
地点 ID 是否存在？数值是否有限且在允许范围内？校验通过后，点击执行才
分发到对应本机函数。这里没有从文字动态生成代码，也没有通用 URL、文件
或命令执行器。

选择“把米写成文字”，把 `"200"` 改成 `200`，比较检查结果。这不只是
显示格式：字符串与数值类型不同。再把两点设成相同 ID：0 米可以完全符合
契约，但它未必回答了原问题。**形状合法、权限允许、任务合适，是不同检查。**

本页只手工实现这三个固定契约的校验，不宣称支持完整 JSON Schema。
真实平台可能支持模式约束、工具选择策略和多次调用；支持的字段与语义应
按具体 API 版本核对，不能把本教学信封原样当成任意服务的请求。

## 把结果交给正确的调用 {#observation}

程序执行后得到一份输出。应用给它附上本次 `call_id` 和工具名，检查结果
是否确实属于当前提议，再交给说明模板。错误案例故意把第一份回执写成
另一个调用 ID：即使距离本身看起来合理，也不能拿它继续回答当前调用。

这三个本机工具规模很小且确定，所以本页还能重新计算并逐字段比较回执。
真实外部服务不一定可重算；通常还需要结构、来源、时间、权限、任务约束
和执行错误检查。**结果与计算一致，不证明地图资料最新，也不证明解释完整。**

修改参数会使旧校验和结果失效，重新检查后才能执行或导出。否则一个页面
很容易出现“新参数旁展示旧结果”的错误。最终说明只把实际回执数值填入
原创模板，不是让 AI 对结果进行事实核查。

## GIS 工具真正计算了什么？ {#geometry}

实验与校园地图共用 6 个公开来源的 WGS84 地点代表点，保留原核对日期，
没有添加道路、建筑轮廓、入口或实时开放信息。

距离使用 Haversine 公式：经纬度转弧度，令
`h = sin²(Δφ/2) + cos φ₁ cos φ₂ sin²(Δλ/2)`，
再计算 `d = 2R asin(√h)`；本演示选择平均地球半径 `R = 6371008.8 m`。
这是假设地球为球体的两代表点间短弧长度，**不是 WGS84 椭球测地线，更
不是可通行道路距离**。数据坐标用 WGS84 不意味着距离计算使用了椭球模型。

半径筛选排除中心点，使用未舍入距离 `d <= radius_m`，再按距离排序。
显示和模板把距离舍入到一位小数，JSON 保留本机计算值。边界归属按未舍入
值判断，不按界面显示值判断。

“半径内没有匹配”只描述这份目录。目录没有食堂点位，就不能据此断言校内
没有食堂。文字检索只按名字、英文名、类别和标签匹配，不会理解“适合晚自习”。

## MCP、权限与不可信内容 {#trust}

MCP 是连接应用、工具和数据源的协议，不是模型本身，也不自动提供 Agent
的规划、能力保证或全部授权。主机负责连接与权限边界；工具描述里的只读
提示不能替代实际访问控制。官方规范也明确提醒：来自不可信服务的工具
注解不能当作可信保证。

工具结果中的文字仍是资料。即使其中写着“忽略规则、发布手记”，也不能
因此变成应用的新指令。本页没有这些工具，所有文字使用安全文本渲染；这
说明受限实现的一种边界，**不宣称靠一个白名单就解决了真实 Agent 的提示注入**。

外部工具还可能超时、返回过期内容、受到调用预算和授权范围限制。应在
应用层限制操作、检查回执并保留可追溯失败，不能把一条顺滑动画当成可靠性。
本页参数只在内存中，导出由使用者主动点击，不读取学习手记或上传资料。
