直接函数、MCP和宿主桥接都返回同一个数时，分别证明了什么？这份
原创AI辅助练习真实运行三份已有教学ZIP，选择同一距离子案例对照。
模型部分沿用预写内存响应，协议与函数实际运行；不比较模型能力或速度。

## 固定一个共同案例 {#case}

使用既有公开六点目录里的`main-library`和`medical-library`，核对的是
WGS84代表点之间的球面弧长。三条路径实际选中结果一致，约1020.225507米，
球面半径6371008.8米；资料核对日仍为2026-11-02。

<a href="{{ '/assets/examples/agent-interface-case.json' | relative_url }}" download="brook-agent-interface-case.json">下载公开案例记录</a>。
记录来自本轮实际Python3.12和固定SDK的CLI，保留所运行ZIP/生成器/公共
目录哈希与计数；没有原始问题、隐藏状态或预写最终回答文本。
运行时间不是来源资料重新核实的时间，也不是新闻更新。

## 先解释每个数，再比较 {#counts}

窄屏可横向滚动这张表；键盘聚焦后可用方向键阅读完整列。

| 路径 | 本次整段CLI实际记录 | 不能据此推断什么 |
| --- | --- | --- |
| 直接函数 | 2次SDK请求尝试、1次本地派发、1份观察 | 不代表2次模型推理；本例provider是预写响应 |

| 宿主桥接 | 2次SDK请求尝试、1次MCP调用尝试、1份接收回执 | 客户端尝试不证明服务端执行次数或实际收费 |

</div>

MCP客户端还检查同ID距离、空目录匹配和两种非法调用，因此总案例数
不能直接拿来给三条路径排效率。没有计时、token、成本或质量榜单。
真实SDK接收脚本回包，也不表示调用了模型。

直接/桥接路径最终有预写文本，仍是`answer_fact_checked:false`。MCP检查
没有要求返回最终回答，所以这一栏是`null`：没有回答需要核实，不是
自动核实为真，也不能把它当Agent回答失败。

## 哪些事实，可以相互核对 {#evidence}

三个ZIP的完整公开目录字节一致；记录核对了来源日期、坐标系、目录大小、
两端ID/代表坐标/来源链接与数值。MCP两条路径实际做了默认discovery，
得到2026-07-28；服务名称/版本是自报信息，不是认证。

provider的`distance_1`只出现在直接/桥接的API调用关联里；MCP检查没有
这份模型API信封，因此记录为`null`。没有把它伪装成SDK内部的协议ID。
协议回执由MCP SDK另外关联，客户端只能陈述自己确实观察到的层次。

网站CI检查保存记录是否仍对应当前ZIP、公共目录和生成器，另外用独立
acos数值参考检查距离。**CI的一致性检查不会重新运行模型或三份SDK**；
真实CLI运行日志单独保留。0.001米是程序数值容差，不是地点定位精度。

## 给正确结果，一个错误解释 {#task}

尝试把1020.225507米写成“图书馆入口间最短步行距离”。数值计算虽然
正确，解释仍越过证据：输入是代表点，没有路网、入口、通行条件或当前
开放数据。三条接口同时给同一数，也不能补齐这些缺失资料。

再给一个空匹配：公开目录找不到食堂，不代表现实没有食堂。最后返回
文本、schema通过和协议连通，都没有代替任务与来源检查。

先为自己的任务写出允许使用的数据、成功条件和一个失败反例，再打开
[既有验收题]({{ '/study/practice/#agent-build-acceptance' | relative_url }})。
这只是学习入口，不会因阅读或下载自动写完成。

## 自己重放与验收 {#replay}

从三篇教程下载各自项目，按README安装固定依赖，再在各自目录运行：

```sh
python demo_offline.py
python client_check.py
python demo_bridge.py
```

三个命令属于不同目录，不能把文件混在一起。本机条件统一按各包的
Python3.11+说明；依赖安装可能需要网络，默认演练没有Key或远端模型。
[直接项目](../agent-project-starter/)、[MCP服务](../agent-mcp-server/)、
[宿主桥接](../agent-mcp-bridge/)分别解释自己的范围。

先保留输出，找到来源和同一距离子案例，再核对每个计数的定义；不要
把所有数相加叫作“智能步数”。若想先看可操作的预算停止，可到
[脚本循环实验]({{ '/playground/agent-runtime/' | relative_url }})：它是真实
本机函数与脚本提议，没有MCP或模型推理。

## 参考记录的边界 {#limits}

2026-11-14实际使用原项目固定openai3.50.0、mcp2.3.0、httpx2 2.16.0。
源码、官方固定引用与完整许可沿用三篇项目说明；原公开六点OSM/ODbL
归属、每条来源与核对日保持，没有重新认证地图或发布新坐标。

静态记录不是持续采集、模型基准、执行证明或通用脱敏器。重放仅选
公开固定情景，生成器白名单提取字段；换SDK、目录或项目后要实际重跑，
不能直接改哈希和版本标签继续声称“已验证”。私人问题与学习手记不属于
这份材料，也没有被读取或上传。
