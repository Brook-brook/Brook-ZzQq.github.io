# 让直线靠近样本：原创梯度练习

Python3.11+，仅标准库，无需pip、模型Key或网络。解压后进入这个目录：

```sh
python3 demo.py
python3 demo.py --case stable
python3 demo.py --case oscillating
python3 demo.py --case guarded
python3 demo.py --case mixed
python3 run_checks.py
```

第一条真正运行一次全批量MSE更新。stable运行最多120步；oscillating用0.2
观察放大；guarded用0.5触及保护后停止；mixed实际采用先0.01后十次0.08。
每条命令输出一份完整JSON，不是预写答案。也可显式保存所有实际结果：

```sh
python3 demo.py --case all > my-gradient-records.jsonl
```

不会读取环境凭据、浏览器学习手记或任意网络服务。网站下载不会自动在
你的电脑上执行程序。这份项目不是神经网络/LLM框架或scikit-learn复现。

## 文件与计算

- samples.json：12个原创人工合成教学点，8训练、4验证，抽象单位；没有
  真实校园坐标、随机采样或真实观察结论。与网页使用同一份公开数据。
- gradient.py：严格读取有界JSON，拒绝重复键、非有限数、布尔数值和未知
  字段；每步从同一组旧参数算梯度，然后同时更新w与b。验证标签只算损失。
- demo.py：明确的有限设置，输出实际数据、起点、每步学习率/参数/梯度/
  训练和验证MSE、以及停止原因。没有自动调参、恢复导入或隐式早停。
- run_checks.py：独立分数方程、有限差分、固定划分隔离、数值边界和输入
  契约检查。通过这些检查不等于模型适用于现实或学习者已经掌握。
- MANIFEST.json：完整明确公开输入的哈希，供内容比较；不是签名或身份认证。

训练目标L=Σ(w*x+b-y)²/n；dw=2Σ((w*x+b-y)*x)/n，db=2Σ(w*x+b-y)/n。
默认w=b=0且η=0.05，第一步应为w=1.485、b=0.10625。训练最小二乘参考
为w=1.98、b=1.0625，MSE=0.04184375。实际浮点比较需给合适容差。
Python使用math.fsum，网页求和实现不同；交叉检查相近数值，不承诺逐位一致。

这个特定凸二次问题的最大Hessian特征值为15，固定η在(0,2/15)内才有
此处的收敛保证。不是其他数据、损失或神经网络的通用界限。最多120步；
拟议参数超过±1e6或训练MSE超过1e12等数值边界时不应用该步，保留最后
正常状态与拒绝记录。步数用完不是训练成功、验证最优或学习者成绩。

这4个验证点反复可见，若据此选设置，就不是独立最终测试。小训练MSE
不证明泛化、因果、数据质量或现实用途。完整记录没有未执行的未来设置，
也不认证发布者或训练数据。代码为MIT原创AI辅助教学实现，第三方边界
与实际参考版本见NOTICE.md；完整许可证随包保留。
