# 从形状到链式梯度

Python3.11+标准库，解压后进入本目录：

```sh
python3 demo.py
python3 run_checks.py
```

第一条实际打印tanh和identity两份JSON，包含四个原创逻辑XOR例子的前向值、
平均二元交叉熵、九个参数梯度与每行的贡献。这里不更新参数，没有优化器、
训练好的分类器、随机样本、独立测试集、语言模型、PyTorch或其他SDK。
调用demo不是自动记录学习完成；浏览器中的对应例子复用同一个neural.py。

neural.py：两个输入、两个隐藏节点、一个输出logit。隐藏层可用tanh或
identity，输出概率由sigmoid计算。九个参数限定±4，输入两维限定±2，
单次二元损失仅接受有限且绝对值不超过1e6的logit及整数0/1标签。
精确字段与有限类型检查是这个小例子的契约，不是通用张量或自动微分框架。

对一个样本：z_j=Σ_k(w_jk*x_k)+b_j，a_j=tanh(z_j)，s=Σ_j(v_j*a_j)+c，
p=sigmoid(s)。目标为四个例子的平均BCE。w00的一行平均梯度贡献为：

```text
(p-y) * v0 * (1-a0²) * x0 / 4
```

完整梯度要把四行加起来。identity模式把隐藏层导数换为1，其输出logit
可折叠为一个仿射式；输出sigmoid仍是非线性函数，不能说整个输出是直线。
当前固定参数没有经过训练，概率输出不代表校准置信度或现实分类能力。

八项检查用中心有限差分独立验证所有九个解析梯度，核对identity折叠式、
平均分母、链式因子、形状和有界输入。每次计算建立新的梯度，不延续上次
值。检查通过不是学习成绩或真实模型能力测评，也没有运行PyTorch autograd。
