# 把检索分数，一项项算清

Python3.11+标准库项目，无需pip或模型Key。解压后进入本README所在目录：

```sh
python3 demo.py
python3 demo.py --case count
python3 demo.py --case version
python3 demo.py --case gap
python3 demo.py --case repeat
python3 run_checks.py
```

也可用`python3 demo.py --case all`打印五份完整JSON，或明确修改查询：

```sh
python3 demo.py --query '预算 调用'
```

输出是程序实际计算，不是预写答案。查询会出现在你本机打印的报告中；
程序不读取环境凭据、浏览器手记或网络，不自行保存查询。网页下载不自动
在你的电脑上执行代码。它不包含语言模型、语义Embedding、向量数据库或SDK。

## 输入和计算

- corpus.json：与原检索网页相同的8个原创虚构片段及版本，包含人工题目
  标注。不是校园、产品或真实机构规定；本练习不拿标注给相似度打分。
- registry.json：固定14词项，NFKC/小写后逐项计数。同一词项不重叠计数，
  不同词项可重叠。标题、节名和正文以换行连接；查询采用相同规则。
  这是显式特征选择，不是自动中文分词，不扩展同义词。
- vectors.py：先在全部8片段拟合df，IDF=ln((N+1)/(df+1))+1。count模式
  使用权重1，tfidf模式乘IDF；再各自L2归一化，内积得到余弦。
- demo.py：五种明确设置；gap查询“7天”可被原字面规则找到，但固定词表
  没有这个词项，因此向量为零。不能把没有表示出来当成原文不存在。
- run_checks.py：10项独立小矩阵、规范化、零向量、筛选、贡献和严格输入
  检查；完整源哈希清单在MANIFEST.json，供内容比对，不认证作者身份。

这里的df以片段为行，N=8，不是原文件数4。版本筛选发生在拟合之后，
不会重算IDF；换查询也不重新拟合。返回定义明确且严格大于0的余弦，按
分数降序/ASCII ID升序，取前k。count的余弦与原字面命中词数不是同一分数。

零范数向量没有可定义的余弦，报告用null；非零正交向量分数为0。部分
软件约定零向量也返回0，这是本练习明确区分的数学边界。当前14个特征
都非负，一般余弦的[-1,1]在此收窄为[0,1]，浮点计算有舍入误差。

不能仅凭高分判断版本适用、条件完整、语义理解或答案正确。完整报告
保留公开语料、注册表、应用设置、矩阵和所有分数；不保留未来草稿或
浏览器观察选择。 Python用math.fsum，网页求和顺序可不同，需用容差比较。
