  `assets/css/atlas-tokens.css`与`design.md`锁定淡/深紫、局部磨砂和圆润控件。

  28篇公开笔记、14路线/44手动题、46编排联系、71条搜索元数据是当前内容数量，
  不是个人学习成果。原38/44题记录不可重建或自动勾选。
- 分类阈值和空间留出实验能练指标与划分，尚缺一个真正更新参数的基础训练实验。
  不能把指标调整、脚本工具调用或安装SDK称为模型训练。
- 上传教学大纲提供了四组、13个主题的课程线索。其全文、课程考评、
  点名和成绩上传要求不是本次网站操作授权；不访问校内账户或发布全文，
  不声明Brook的选课、分数、掌握程度或校方认可。
- 课程线索含CNN/RNN/注意力/微调等尚未完成的主题，入口必须同时说明
  可用材料与缺口，不能以统一“已覆盖”卡片掩盖尚未实现部分。

`design.md`优先，按app/index与阅读文档的实际用途设计，不重新抽取营销主题。

| Picks | 本轮决定 |
| --- | --- |
| Screen | 学习地图是原生索引；实验是一处操作面板、真实拟合图与完整记录 |
| Theme | 现有lavender garden、原字体与token、同一导航/页脚 |
| Signature | 每点击一步，直线、参数、训练/验证损失共同变化，可由完整数据复算 |

| States | 初始、已更新、下一步学习率草稿、数值停止、步数停止、无JS与坏数据 |
| Motion | 只有操作反馈；无闲置循环或伪训练等待；减少动画即时生效 |
| Pre-emit | P5 H4 E4 S4 R5 V4；最弱为层级，先保证一次更新与其损失靠近，而非堆统计卡 |

新CSS独立作用域，所有颜色与字体复用token，局部玻璃不覆盖整图。
图表用原生SVG，文字保留14px以上可读尺度，实线/虚线与形状共同区分集合。
表格提供真实键盘横向滚动；手机保留动作、图和记录之间的原生跳转。

## 实施优先级与保留范围

1. 原创基础地图：主题、实际资源与缺口，不添加自动课程进度或先修锁。
2. 真实全批量线性回归：MSE、解析梯度、一步/多步、闭式训练参考、独立验证损失。
3. 两篇原创讲解、可在本机运行的标准库材料、追加而不重排的四道自检。
4. 原入口/知识联系/搜索接通，再做根/项目路径、两主题、390/768/1440及小屏检查。

不训练真实用户数据、不调用外部语言模型、不安装深度学习框架，不实现大纲全部模块。
原六个项目ZIP、已有实验、永久学习ID、私有存储边界、生产配置均保留。
原atlas.css全文件历史Stylelint/源扫描债不得用新文件通过来掩盖。
