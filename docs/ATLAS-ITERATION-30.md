## 可以直接使用的内容

| 入口 | 可以做什么 | 实际范围 |
| --- | --- | --- |
| `/study/ai-foundations/` | 在四组、13个主题中选一个真实资源入口 | 入门材料、局部实验、后续主题表示资源可用性，不表示整章覆盖或个人掌握 |
| 先确定任务，再谈模型 | 区分特征、目标、模型、损失与指标 | 原创讲解与两道手动自检；不假造模型成绩 |
| 让梯度真正更新一条直线 | 从训练MSE复算偏导，比较一步、多步与学习率 | 12个原创合成点，固定8训练/4验证；抽象单位，无校园实测或随机采样 |
| `/playground/linear-regression/` | 实际计算参数、拟合线、两组损失和完整记录 | 原生JS/SVG全批量梯度；真实训练这个小回归模型，不调用外部语言模型 |
| 从形状，走到链式梯度 | 用四个逻辑例子核对2→2→1网络的前向值与九个参数梯度 | 手写tanh/identity与平均BCE，不更新参数、无优化器或框架自动微分 |
| Python第六例 `#neural-gradients` | 编辑同一份原创源码，再明确加载、运行、重置 | 实际Pyodide0.27.7；保留原五例、异步/JSON预选、错误、停止、超时与输出上限 |
| 两份Python ZIP | 在自己的Python3.11+运行演示和独立检查 | 仅标准库，不需pip或模型Key；完整源码、原创数据、清单与MIT/CPython许可 |

两份包分别为9条目和8条目。回归包实际运行12项检查与5个CLI设置；神经
网络包实际运行8项检查与两种隐藏层设置。网页与Python完整回归轨迹做
数值容差比较，不承诺浮点逐位一致或与某个框架等价。

现在共有31篇公开笔记、15条路线/49道手动自检、53条人工编排联系和77条
公开搜索元数据。五个永久ID只追加在原44项之后；旧v1原始字节和导出在
路线/练习两页保持，只有明确填写或勾选才扩展。没有新手记存储、隐式
完成、先修锁、自动评分或私人搜索索引。原六个项目ZIP保持字节不变。

推荐从基础地图进入回归实验，按一次更新，读对应推导，再在原自检页
写自己的解释；已有基础可直接回原AI/Agent路线。聚类/PCA、CNN、RNN和
微调等缺口仍明确列为后续主题。教学大纲仅提供主题线索，未公开其全文，
未执行校内考评要求，也未推断Brook的选课、成绩或进度。

## 交互、视觉与科学边界

沿用淡紫/深紫、磨砂花园和既有导航。学习地图采用原生分组索引，实验
只给设置区一层轻玻璃，拟合图与损失图不套重复卡片。集合同时用形状和
线型区分；SVG viewBox跟随实际尺寸，正常图中文字保持14px。损失轴明确
为`log10(1+MSE)`显示变换，训练仍用原始MSE。

每步从同一旧w/b同时更新；验证标签不进入梯度、闭式训练参考或数值停止。
默认第一步w=1.485、b=0.10625。训练闭式参考w=1.98、b=1.0625，MSE=
0.04184375。固定步长界限`0<η<2/15`只属于本例凸二次问题，不是神经网络
通用保证。最多120步，越数值边界的拟议更新不应用，最后有效状态与完整
拒绝记录保留。反复查看的验证点不是独立最终测试。

单样本观察只展开当前残差、损失与梯度贡献，不训练、不改变下载。JSON
保存实际全部数据、起点、已应用步骤、旧参数梯度及停止原因，排除未来
草稿、观察选择和私有手记。网络例的BCE使用自然对数，不与回归图的
log10显示轴混淆；identity隐藏层可折叠为仿射logit，输出sigmoid仍非线性。

实际截图先发现旧通用header/section/SVG样式挤压图例；已做局部重置。
320px放大文字检查又发现小数被挤成两行，现按rem最小宽度自动重排，保持
完整数值；很小的非零梯度用科学计数法。按钮停用时焦点转到真实停止
状态，180ms有限反馈随实时减少动画偏好取消，没有闲置动画或伪训练等待。

只给内部构造并深冻结的状态复用不可变前缀；外部可变或仅浅冻结记录仍
完整重放校验。表格只追加新步骤，新运行才替换；格式器复用而非每格创建。
一次本地4倍CDP CPU的12次十步操作中，同步处理器中位数149.25→22.2ms，
最大250.6→46.5ms。测量时另有浏览器任务运行；这是局部轨迹，不能推广为
INP、物理设备或站点性能基准。完整原始值与未奏效的首轮缓存比较保留。

完整浏览器命令随后在梯度项捕获一次负宽度SVG裁切错误。图表现在只在
容器有足够绘制宽度时生成几何，隐藏时保留上次有效图，恢复尺寸后由
ResizeObserver重绘。专门检查真实隐藏、实际更新和恢复显示，验证完整
记录不丢失且控制台无负尺寸错误；原始失败日志保留，不改写为整套通过。
