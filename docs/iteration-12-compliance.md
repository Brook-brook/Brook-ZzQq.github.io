# 第十二轮资源与隐私核对

核对日期：2026-11-12。范围：首页路线、公开内容搜索、作品筛选与验证。
基于第十一轮 748a582，保留已有许可、来源与功能边界。

- 未增加、升级或替换依赖；package.json 只扩展现有测试命令，lockfile 不变。
- 搜索、筛选与排版为本项目新写的原生 JS/CSS/Ruby/Liquid，未复制第三方实现。
  放大镜 SVG 为本轮原创简单几何；Mote 复用已有本地原创资源。没有新图片、
  地图数据、图标包、字体、CDN 或动画库。
- 搜索数据来自通过发布护栏的公开笔记元信息、既有学习路线与项目，以及本轮
  编写的真实页面/实验目录。没有新增科研结论、校园点位或编造的个人成果。
- 新索引只含标题、摘要、关键词、类型、状态及站内链接，不含正文。未复核研究、
  draft、published:false 均由真实 Jekyll 构建测试验证排除，包括 --unpublished。
  撤回研究后的同目录重建不会保留旧搜索记录。
- 搜索输入只在内存匹配，不发送查询、不存 URL/历史/localStorage，也不读私人手记。
  首次打开面板才请求静态公开索引；失败可重试，超时 8 秒、最大 512KiB/1000 条，
  内部路径限于当前 baseurl；无 JS 或无 dialog 时仍有完整目录。服务器仍可能
  留下普通静态页面请求日志，不能据此宣称网站匿名或没有任何访问日志。
- 没有创建新存储键、登录、追踪、平台连接、自动采集任务或自动部署。
  保留学习/观察台本机数据、收藏、备份与原有隔离规则。浏览器测试的私人哨兵
  为合成测试文字，不是 Brook 的真实手记。
- 未改变 Pages 来源、生产工作流、默认分支、observatory-ops/data，也不合并 PR。

既有完整许可证继续保留在 licenses/。人工图像检查、浏览器验证和限制见
[交付记录](ATLAS-ITERATION-12.md)。
