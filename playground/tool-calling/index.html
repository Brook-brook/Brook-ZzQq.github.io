一次成功执行，还留下哪些问题？

  1. 参数合法 ≠ 意图正确。两点相同也可以得到合法的 0 米；它仍可能答错问题。文字检索不会理解“安静”或推断开放时间。
  2. 空结果 ≠ 现实中不存在。半径只查这份目录，排除中心点；未舍入距离 ≤ 半径才入选。食堂与宿舍没有收录点位。
  3. 距离模型有范围。Haversine 公式采用 6371008.8 米平均地球半径，输出球面短弧长度；不是 WGS84 椭球测地线、建筑入口间距离或步行路线。
  4. 工具结果是资料，不是指令。本页只按白名单分发，始终按文字显示参数与结果。真实 Agent 还需处理不可信内容、权限、预算、超时与失败。
